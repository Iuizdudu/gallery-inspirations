<a id="about"></a>
<img src="https://readme-typing-svg.herokuapp.com?font=Lexend+Giga&size=24&pause=1000&color=38BDF8&vCenter=true&width=500&height=28&lines=ABOUT+THE+PROJECT" width="500"/>

**Gallery Inspirations** is a curated, distraction-free digital catalog built for designers, software engineers, and product creators.

It rejects the bloated model of screenshot-heavy design feeds and slow intermediary pages. Instead, it prioritizes **speed, typographic hierarchy, and instant 1-click access to production websites**.

> [!NOTE]
> **Note:** The app is built for maximum **speed and focus**: each list item displays only its numeric index, the direct link title, concise bilingual editorial descriptions, and the interactive visit button.

> [!TIP]
> **Quick Navigation:** Press <kbd>Ctrl</kbd> + <kbd>K</kbd> (or <kbd>Cmd</kbd> + <kbd>K</kbd> on macOS) anytime to trigger the global **Spotlight Command Palette** and find any resource instantly without touching the mouse.

<a id="installation"></a>
<img src="https://readme-typing-svg.herokuapp.com?font=Lexend+Giga&size=24&pause=1000&color=38BDF8&vCenter=true&width=500&height=28&lines=LOCAL+SETUP" width="500"/>

To run **Gallery Inspirations** locally:

```bash
# 1. Clone the repository
git clone https://github.com/luizeduardo98r4/gallery-inspirations.git

# 2. Enter directory
cd gallery-inspirations

# 3. Install dependencies
npm install

# 4. Start development server
npm run dev
```

Open your browser at:
```
http://localhost:3000
```

<img src="https://readme-typing-svg.herokuapp.com?font=Lexend+Giga&size=24&pause=1000&color=38BDF8&vCenter=true&width=500&height=28&lines=HOW+TO+CONTRIBUTE" width="500"/>

Contributions are kept minimal. **Only the fields actually displayed in the UI are required**:

```typescript
// src/data/references.ts
{
  id: "stripe-press",
  title: "Stripe Press",
  categoryId: "landing",
  url: "https://press.stripe.com/",
  descriptionPt: "Publicações sobre ideias e inovação com direção de arte e tipografia editorial de excelência.",
  descriptionEn: "Publications on ideas and innovation with world-class art direction and typography.",
  popularity: 96 // Optional (1 to 100)
}
```

<a id="vercel"></a>
<img src="https://readme-typing-svg.herokuapp.com?font=Lexend+Giga&size=24&pause=1000&color=38BDF8&vCenter=true&width=500&height=28&lines=DEPLOY+ON+VERCEL" width="500"/>

Deploy your own instance of **Gallery Inspirations** with 1 click:

1. Push the code to your GitHub repository.
2. In [Vercel](https://vercel.com), select **Add New Project**.
3. Import the repo. Vite build settings are recognized automatically:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. Click **Deploy**.
