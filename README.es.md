<a id="sobre"></a>
<img src="https://readme-typing-svg.herokuapp.com?font=Lexend+Giga&size=24&pause=1000&color=38BDF8&vCenter=true&width=500&height=28&lines=ACERCA+DEL+PROYECTO" width="500"/>

**Gallery Inspirations** es un catálogo digital curado y minimalista diseñado para diseñadores, ingenieros de software y creadores de productos web.

El proyecto prescinde intencionalmente del formato pesado de galerías llenas de capturas de pantalla gigantes, sobrecarga visual y páginas intermedias innecesarias. Aquí, la máxima prioridad es la **velocidad, la elegancia tipográfica y el acceso directo al trabajo real en producción**.

> [!NOTE]
> **Nota de Diseño:** La aplicación está optimizada para **máxima agilidad y enfoque**: cada elemento de la lista muestra únicamente el índice numérico, el título con enlace directo, la descripción editorial y el botón interactivo de visita rápida.

> [!TIP]
> **Navegación Rápida:** Presiona <kbd>Ctrl</kbd> + <kbd>K</kbd> (o <kbd>Cmd</kbd> + <kbd>K</kbd> en Mac) en cualquier momento para abrir el **Spotlight Command Palette** y buscar al instante cualquier sitio, categoría o recurso sin tocar el mouse.

<a id="caracteristicas"></a>
<img src="https://readme-typing-svg.herokuapp.com?font=Lexend+Giga&size=24&pause=1000&color=38BDF8&vCenter=true&width=500&height=28&lines=CARACTERISTICAS" width="500"/>

La interfaz está enriquecida con microinteracciones ópticas avanzadas de la suite **React Bits**:

| Componente | Visual | Comportamiento e Interacción |
| :--- | :---: | :--- |
| **SpecularButton** | 💎 | Botón de cristal dark glass con reflejo luminoso perimetral que sigue la proximidad del cursor mediante Canvas 2D de alto rendimiento. |
| **StarBorder** | ⭐ | Botón con destello estelar en órbita constante por el borde redondeado (`hover="lap"` y pulsación táctil `clickPulse`). |
| **ParticleText** | 🌌 | Título monumental en la página principal animado con física de partículas dinámicas y dispersión interactiva. |
| **PillNav** | 💊 | Barra de navegación flotante estilo pill con indicador de sección activa y transiciones fluidas. |
| **Command Palette** | 🔍 | Búsqueda global instantánea accesible mediante atajos de teclado (<kbd>↑</kbd> <kbd>↓</kbd> <kbd>Enter</kbd> <kbd>Esc</kbd>). |
| **Barra Lateral Retráctil** | 📑 | Menú lateral colapsable con contadores exactos por categoría y navegación instantánea. |

> [!IMPORTANT]
> **Rendimiento Garantizado:** Todos los efectos ópticos utilizan aceleración gráfica en Canvas 2D sin sobrecargar la memoria GPU, eliminando cualquier riesgo de colapso por límite de contextos WebGL en navegadores modernos.

<a id="instalacion"></a>
<img src="https://readme-typing-svg.herokuapp.com?font=Lexend+Giga&size=24&pause=1000&color=38BDF8&vCenter=true&width=500&height=28&lines=INSTALACION+LOCAL" width="500"/>

Para ejecutar **Gallery Inspirations** localmente en tu entorno:

```bash
# 1. Clonar el repositorio
git clone https://github.com/Iuizdudu/gallery-inspirations.git

# 2. Entrar en la carpeta del proyecto
cd gallery-inspirations

# 3. Instalar dependencias
npm install

# 4. Iniciar el servidor local de desarrollo
npm run dev
```

Abre tu navegador en:
```
http://localhost:3000
```

> [!TIP]
> **Compilación para Producción:** Para generar los activos optimizados y listos para despliegue:
> ```bash
> npm run build
> ```
> Los archivos listos para producción se generarán en la carpeta `/dist`.

<a id="contribucion"></a>
<img src="https://readme-typing-svg.herokuapp.com?font=Lexend+Giga&size=24&pause=1000&color=38BDF8&vCenter=true&width=500&height=28&lines=COMO+CONTRIBUIR" width="500"/>

El proceso de contribución está diseñado para ser directo y rápido. **Solo se requieren los campos que se muestran en pantalla**:

```typescript
// src/data/references.ts
{
  id: "stripe-press",
  title: "Stripe Press",
  categoryId: "landing",
  url: "https://press.stripe.com/",
  descriptionPt: "Publicações sobre ideias e inovação com direção de arte e tipografia editorial de excelência.",
  descriptionEn: "Publications on ideas and innovation with world-class art direction and typography.",
  popularity: 96 // Opcional (1 a 100)
}
```

### Pasos Rápidos para Contribuir:
1. Haz un **Fork** de este repositorio en GitHub.
2. Crea una rama para tu nueva referencia:
   ```bash
   git checkout -b feature/agregar-nombre-del-sitio
   ```
3. Añade la referencia al array `REFERENCES` en `src/data/references.ts`.
4. Haz commit y envía tu **Pull Request (PR)**.

> [!NOTE]
> Consulta la [**Guía de Contribución Completa (CONTRIBUTING.md)**](./CONTRIBUTING.md) para más detalles y convenciones de formato.

<a id="vercel"></a>
<img src="https://readme-typing-svg.herokuapp.com?font=Lexend+Giga&size=24&pause=1000&color=38BDF8&vCenter=true&width=500&height=28&lines=DESPLIEGUE+EN+VERCEL" width="500"/>

Para publicar tu propia instancia de **Gallery Inspirations** en Vercel con 1 clic:

1. Sube tu código a tu repositorio de GitHub.
2. Ve a tu panel en [Vercel](https://vercel.com) y selecciona **Add New Project**.
3. Importa el repositorio. La configuración de Vite es detectada automáticamente:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
   - **Install Command**: `npm install`
4. Haz clic en **Deploy**.

> [!TIP]
> La aplicación es completamente estática y compatible con CDNs perimetrales en todo el mundo, garantizando tiempos de carga casi instantáneos y puntaje máximo en Lighthouse.
