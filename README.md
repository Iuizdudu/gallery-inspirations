<a id="sobre"></a>
<img src="https://readme-typing-svg.herokuapp.com?font=Lexend+Giga&size=24&pause=1000&color=38BDF8&vCenter=true&width=500&height=28&lines=SOBRE+O+PROJETO" width="500"/>

O **Gallery Inspirations** é uma biblioteca digital curada e minimalista voltada para designers, engenheiros de software e criadores de produtos digitais. 

O projeto rejeita deliberadamente o formato cansativo de galerias repletas de screenshots pesados, poluição visual e páginas intermediárias redundantes. Aqui, a prioridade máxima é a **velocidade, a elegância do código e o acesso direto ao trabalho real em produção**.

> [!NOTE]
> **Nota:** A aplicação foi arquitetada para máxima **agilidade e foco**: cada item da lista apresenta apenas o índice numérico, o título com link direto, a descrição editorial em português/inglês e o botão interativo de visita rápida.

> [!TIP]
> **Dica de Navegação Rápida:** Pressione <kbd>Ctrl</kbd> + <kbd>K</kbd> (ou <kbd>Cmd</kbd> + <kbd>K</kbd> no Mac) a qualquer momento para abrir o **Spotlight Command Palette** e pesquisar instantaneamente por qualquer site, recurso ou categoria sem encostar no mouse.

<a id="recursos"></a>
<img src="https://readme-typing-svg.herokuapp.com?font=Lexend+Giga&size=24&pause=1000&color=38BDF8&vCenter=true&width=500&height=28&lines=PRINCIPAIS+RECURSOS" width="500"/>

A experiência é enriquecida com microinterações ópticas de ponta da suíte **React Bits**:

| Componente | Visual | Comportamento e Interação |
| :--- | :---: | :--- |
| **SpecularButton** | 💎 | Botão com efeito de vidro dark glass e feixe de luz que acompanha a proximidade e o movimento do mouse via Canvas 2D de alta performance. |
| **StarBorder** | ⭐ | Botão com estrela e rastro luminoso que viaja suavemente pela borda arredondada (`hover="lap"` e pulso tátil `clickPulse`). |
| **ParticleText** | 🌌 | Título monumental na página inicial animado por física de partículas dinâmicas com modo de dispersão e agrupamento. |
| **PillNav** | 💊 | Barra de navegação flutuante em formato de pílula glass com indicador de seção ativa e transição suave. |
| **Command Palette** | 🔍 | Sistema de busca global instantâneo com atalhos de teclado (<kbd>↑</kbd> <kbd>↓</kbd> <kbd>Enter</kbd> <kbd>Esc</kbd>). |
| **Sidebar Retrátil** | 📑 | Menu lateral expansível e colapsável com contadores individuais por categoria e navegação rápida. |

> [!IMPORTANT]
> **Importante:** Todos os efeitos visuais utilizam aceleração gráfica otimizada em Canvas 2D sem consumo excessivo de memória GPU, eliminando qualquer risco de estouro de contextos WebGL no navegador.

<a id="instalacao"></a>
<img src="https://readme-typing-svg.herokuapp.com?font=Lexend+Giga&size=24&pause=1000&color=38BDF8&vCenter=true&width=500&height=28&lines=INSTALACAO+LOCAL" width="500"/>

Para executar o **Gallery Inspirations** localmente em seu computador:

```bash
# 1. Clone o repositório
git clone https://github.com/luizeduardo98r4/gallery-inspirations.git

# 2. Acesse a pasta do projeto
cd gallery-inspirations

# 3. Instale as dependências
npm install

# 4. Inicie o servidor local de desenvolvimento
npm run dev
```

Abra seu navegador em:
```
http://localhost:3000
```

> [!TIP]
> **Dica para Build de Produção:** Para gerar o pacote estático otimizado para deploy, execute:
> ```bash
> npm run build
> ```
> Os arquivos finais serão compilados na pasta `/dist`.

<a id="contribuicao"></a>
<img src="https://readme-typing-svg.herokuapp.com?font=Lexend+Giga&size=24&pause=1000&color=38BDF8&vCenter=true&width=500&height=28&lines=COMO+CONTRIBUIR" width="500"/>

O modelo de contribuição do Gallery Inspirations foi simplificado ao máximo. **Apenas os campos realmente exibidos na tela são exigidos**:

```typescript
// src/data/references.ts
{
  id: "stripe-press",
  title: "Stripe Press",
  categoryId: "landing",
  url: "https://press.stripe.com/",
  descriptionPt: "Publicações sobre ideias e inovação com direção de arte e tipografia editorial de excelência.",
  descriptionEn: "Publications on ideas and innovation with world-class art direction and typography.",
  popularity: 96 // Opcional (1 a 100)
}
```

### Passo a Passo Rápido:
1. Faça um **Fork** deste repositório no GitHub.
2. Crie uma branch para a nova referência:
   ```bash
   git checkout -b feature/adicionar-nome-do-site
   ```
3. Adicione a referência ao array `REFERENCES` em `src/data/references.ts`.
4. Faça o commit e envie seu **Pull Request (PR)**.

> [!NOTE]
> Para orientações detalhadas, consulte o [**Guia de Contribuição Completo (CONTRIBUICAO.md)**](./CONTRIBUICAO.md).

<a id="vercel"></a>
<img src="https://readme-typing-svg.herokuapp.com?font=Lexend+Giga&size=24&pause=1000&color=38BDF8&vCenter=true&width=500&height=28&lines=DEPLOY+NA+VERCEL" width="500"/>

Para colocar sua instância do **Gallery Inspirations** online na Vercel com apenas 1 clique:

1. Suba o código para o seu repositório no GitHub.
2. Acesse o seu painel na [Vercel](https://vercel.com) e selecione **Add New Project**.
3. Importe o repositório. As configurações do Vite são detectadas automaticamente:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
   - **Install Command**: `npm install`
4. Clique em **Deploy**.

> [!TIP]
> A aplicação é 100% estática e otimizada para CDNs globais, garantindo carregamento instantâneo e pontuação máxima no Google Lighthouse.
